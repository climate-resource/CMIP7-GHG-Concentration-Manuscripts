Consistent boundary conditions are a key input to large model intercomparison projects.
Here we present the greenhouse gas concentration boundary conditions, i.e. forcings,
to be used for the pre-industrial control (piControl) and historical experiments
in the seventh phase of the Coupled Model Intercomparison Project (CMIP7).
We show that, despite the use of updated input data sources, changes between the previous phase's forcings (CMIP6) and CMIP7 forcings are small:

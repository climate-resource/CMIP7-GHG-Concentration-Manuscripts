% Why appendices (and not a supplement):
% Copernicus says appendices are for "Additional figures, tables, as well as technical and theoretical developments
% which are not critical to support the conclusion of the paper, but which provide extra detail and/or support
% useful for experts in the field and whose inclusion in the main text would disrupt the flow of descriptions or demonstrations"
% and that "Supplementary material is reserved for items that cannot reasonably be included in the main text or as appendices.
% These may include short videos, very large images, maps, CIF files, as well as short computer codes".
% Our extra figures are exactly the former and can reasonably be included as appendices,
% so they go here rather than in a supplement.
% https://publications.copernicus.org/for_authors/manuscript_preparation.html
% (section "Appendices and Supplements/Supplementary Material", checked 2026-10-07)
%
% Each \section is a new appendix (A, B, ...).
% Figures and tables are numbered within their appendix (A1, A2, ..., B1, ...),
% so put them in the appendix section they belong to.
% Put a \clearpage before each \section and at the end of the file,
% so each appendix's figures are flushed before the next appendix starts
% (otherwise they can float into the next appendix).
% The same goes for each \subsection.
% The figures of the groups of gases which share a figure layout (e.g. the gases processed like CFC12)
% are generated by the build (`src/local/historical_ghg_forcing_for_cmip7/appendix_figures.py`)
% and inlined in place of their tags (the `@...-appendix-figures@` lines below), so edit their captions there.
% Their captions just point to the figure of the same kind for CFC12 (or C_4F_10).
% A figure which is already included anywhere in the text (including by hand in this file)
% is left out of the generated figures (e.g. CFC12's), so it isn't in the manuscript twice.
% \appendix and \noappendix are added by the build, don't add them here.
%
% Despite what the Copernicus template says, we don't use \appendixfigures or \appendixtables:
% they break the numbering.
% The template only asks for them if all figures and tables are put after the reference list
% (its "Option 2"). We put figures and tables in the sections they belong to (its "Option 1"),
% for which \appendix already numbers them per appendix (A1, A2, ..., B1, ...).
% \appendixfigures also steps the section counter, on top of the step from \section,
% so using it as well (tested 2026-10-07, one after each appendix \section)
% numbered the figures in Appendix B as C1, C2, ...

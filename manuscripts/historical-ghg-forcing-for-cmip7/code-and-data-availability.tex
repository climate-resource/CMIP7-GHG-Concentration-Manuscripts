The code and data to build the underlying dataset is available at
\newline \mbox{\url{https://github.com/climate-resource/CMIP-GHG-Concentration-Generation}}.
The full set of inputs and outputs from the run that produced each dataset is archived on Zenodo
and included in each file's `doi' attribute.
For the v1.0.0 dataset described in this manuscript, the Zenodo archive is available at
\url{https://doi.org/10.5281/zenodo.14892947}.
The data is also available from the Earth System Grid Federation (ESGF, \citealp{esgf_docs_2025})
via its search and download APIs or its Metagrid front-ends, e.g.
\url{https://metagrid.esgf-west.org/search?project=input4MIPs&activeFacets=\%7B\%22source_id\%22\%3A\%22CR-CMIP-1-0-0\%22\%7D}.
For more complete guidance on accessing forcings via different methods
and on how to use them in different CMIP7 experiments, please see
\newline \mbox{\url{https://wcrp-cmip.github.io/cmip7-guidance/docs/CMIP7/Experiment_set_up_and_Forcings/}}
and the experiment pages given there
\newline (e.g. for piControl, \mbox{\url{https://wcrp-cmip.github.io/cmip7-guidance/docs/CMIP7/Experiment_set_up_and_Forcings/picontrol/}}).
